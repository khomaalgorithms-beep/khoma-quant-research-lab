# Synthetic sample data

These files are **simulated**, not real market prices. They were generated by
`scripts/make_sample_data.py` (seed = 42) using a two-regime random model
(see `generate_synthetic_market` in `src/data_loader.py`).

They exist so that the tests, notebook and dashboard work offline and
reproducibly. Results computed on them say nothing about real assets.
Synthetic assets have no dividends or splits, so `Adj Close` equals `Close`.
